## Public-health leaflet exercises

Anika Pellan coordinates reading exercises for public-health leaflets with the Health Literacy program. The classroom set includes fictional leaflets, a vocabulary sheet and a comparison grid for identifying audience, purpose and reading level. Learners use the grid to describe how a public-information page is organized, rather than to judge a real person’s health choices.

## Community pavilion collection

The materials are stored in the Community Health Pavilion’s teaching area alongside a map table and leaflet racks. Pellan keeps the source examples grouped by topic and format so that the exercises can be repeated with the same set. The Primary Care connection reflects the provider’s fictional department assignment; the program and community pages describe the educational work. Nothing here constitutes health guidance or a real public service.

## Reading the campus map

Transit Access is a guide to the symbols used on fictional Alder Coast campus maps. A solid line marks a pedestrian path, a shaded band represents a covered link between buildings, and a separate icon identifies a transit concept in the map legend. The symbols describe categories in the demonstration map; they do not indicate a real route or service.

## Access information as a collection

The guide shows how a map legend can distinguish entrances, level changes and covered connections. A sample map entry pairs a location name with a symbol key and a short note about the information's scope. Readers can compare the map with the Community Health Pavilion location description and see how a campus guide uses the same building label in a different context.

This page explains a fictional map vocabulary. It includes no addresses, departure times, transit provider details or current travel directions.

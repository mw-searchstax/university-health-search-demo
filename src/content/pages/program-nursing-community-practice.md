## Reading community information

Nursing Community Practice is a fictional course about interpreting community-information materials. A sample project compares map legends, leaflet audiences and source notes using invented campus examples, with attention to how each document identifies its intended readers.

## Project references

Students can compare the sample materials with the broader Nursing Studies collection and its classroom documentation exercises. The closed enrollment label is fictional; it includes no application process or reopening date.

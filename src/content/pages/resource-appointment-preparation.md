## Inside a sample packet

This fictional packet uses a cover sheet, a topic divider and a document index to show how appointment materials might be grouped in an institutional collection. Each page is a sample artifact with an invented title and no personal information. The index describes the role assigned to each page within the packet.

## Reading the collection

The packet is catalogued with Primary Care teaching materials. Its labels are intended to help readers distinguish a summary page from a background sheet or reference section. This resource describes document organization only; it does not offer instructions for preparing for an appointment, scheduling a visit or obtaining care. The related referral page describes another fictional document type in the same collection.

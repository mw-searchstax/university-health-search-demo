## Mock apartment plans

Mina Corven organizes mock apartment layouts for Rehabilitation seminars. The plans show furniture placement, doorways and circulation routes in an invented setting. Students use the drawings to compare how a room plan communicates its dimensions and intended use. A companion folder contains annotated versions that call out design features without describing any real resident or home.

## Materials at the center

The Rehabilitation Center displays the plans beside adjustable classroom furniture and a set of blank design grids. Corven keeps the source sketches with the display so viewers can see how each version was revised. These materials connect the service’s academic discussion of function and environment with practical questions of layout. The page describes teaching resources only; it does not assess a person’s needs or recommend changes to a living space.

# Appointment Packet Guide

Fictional demonstration website. Not a real healthcare provider.

## A packet as a document set

This guide describes how an invented university teaching office might arrange a sample appointment packet for a classroom display. It is a catalogue of document roles, not a checklist for visitors and not a source of preparation instructions. The packet has a cover label, a fictional visit summary, a glossary card and a records index. Each item uses a distinct heading so students can discuss how document titles signal purpose.

## Cover label

The cover label identifies the packet as a teaching example and groups its pages under a single fictional visit code. The code is a made-up classroom identifier; it is not an account number or a key to a real record. A small version note helps learners compare successive sample packets without implying that the material describes current institutional policy.

## Visit summary

The sample summary uses neutral fields such as topic, document date and teaching unit. Its invented entries demonstrate the difference between a label and a statement of fact. A margin note identifies where an example value appears, while a companion glossary defines the terms used in the summary. The display avoids real names, addresses, appointment times and contact channels.

## Glossary and records index

The glossary card groups general vocabulary by topic rather than by clinical recommendation. The records index lists the sample pages in reading order and gives each one a short descriptive label. Students can compare the index entry with the heading printed on its page, then consider which words would help a reader find that document in a library catalogue.

## Teaching use

In a document-design exercise, learners can identify repeated labels, distinguish a section title from a document title and describe how a packet communicates its structure. The example has no detachable forms, signature blocks, instructions to complete a task or route to a service. It exists only as a fictional, text-based classroom artifact for the Alder Coast University Health search demonstration.
